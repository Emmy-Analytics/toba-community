TOBA COMMUNITY — BRIGHT MULTI-PAGE STARTER

PAGES
- index.html: Home
- tobaladies.html: Tobaladies
- tobadeli.html: Tobadeli
- events.html: Events + category filters
- merchandise.html: Merchandise + category filters + demo cart
- gallery.html: Gallery + category filters
- partnership.html: Partnership inquiry form (demo only)
- style.css: shared responsive design
- script.js: page content and interactions
- assets/: supplied Tobaladies logo and crocodile-head image

RUN IN VS CODE
1. Extract the ZIP file.
2. Open the extracted `toba-community-v2` folder in VS Code.
3. Open `index.html` with Live Server.
4. Use the navigation to visit the other separate HTML pages.
